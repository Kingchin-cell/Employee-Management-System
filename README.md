# 👨‍💼 职工管理系统 v1.0
> 基于 C++ 开发的控制台版职工信息管理工具，实现职工信息全生命周期管理，支持增删改查、排序、本地文件数据持久化，适用于大学课程设计与C++练手项目。

## ✨ 核心功能
- [x] 新增职工信息录入
- [x] 展示全部职工信息
- [x] 按编号删除离职职工
- [x] 修改已有职工资料
- [x] 按编号/姓名查找职工
- [x] 职工信息按编号自动排序
- [x] 一键清空所有职工数据
- [x] 本地文件持久化存储，重启数据不丢失

## 🚀 快速使用
### 方式一：直接下载运行
1. 前往仓库 Release 页面下载压缩包
2. 解压到任意文件夹
3. 双击 职工管理系统.exe 即可打开

> 温馨提示
> Windows  Defender 若拦截：点 更多信息 → 仍要运行 即可正常启动。

### 方式二：本地源码编译
1. 下载或克隆整个项目源码
2. 用 Visual Studio 2022 打开 .sln 解决方案
3. 编译配置：Release | x86 ，运行库设置为 多线程 (/MT)
4. 重新生成解决方案，在 x86/Release 取出 exe 即可运行
